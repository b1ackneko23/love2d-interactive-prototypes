# LÖVE2D Interactive Prototypes

A laboratory repository exploring 2D physics simulations, real-time math, and game architecture using Lua and the LÖVE framework[cite: 4]. These prototypes serve as direct testbeds for control loops and simulation intuition applicable to robotics[cite: 4].

## Projects
- **01-Vector Kinematics:** Discrete time integration, velocity vectors, acceleration, and restitution boundaries.
- **02-Breakout State Machine:** Discrete game states (Menu, Active, Paused, Game Over) and AABB collision resolution.

## Requirements & Execution
Run projects with [LÖVE](https://love2d.org/):
```bash
love 01-vector-kinematics/
